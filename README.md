# Goosescope

**EN** — Point your phone's camera at something and Goosescope tells you its color.
Freeze the image to learn more about the exact shade. Made for colorblind people.
Fully offline: no account, no network, no image ever saved.

**FR** — Pointe la caméra vers un objet et Goosescope te dit sa couleur. Fige
l'image pour en savoir plus sur la nuance exacte. Fait pour les personnes
daltoniennes. Entièrement hors ligne : aucun compte, aucun réseau, aucune image
enregistrée.

Android 13+. MIT license.
